## 🧩 Featured Projects

### 📘 Syllabye — Senior Capstone Project

**Role:** Product Owner | Front-End Contributor | System Architecture & Documentation  
**Stack:** React, Vite, JavaScript, HTML5, CSS, Tailwind CSS, Bootstrap, Firebase, Azure Static Web Apps, Google Cloud, Git/GitHub, react-i18next

Syllabye is a full-stack web application designed to streamline academic syllabus creation, access, upload, download, and management for professors and students.

**Highlights:**
- Built a componentized React application using Vite, JavaScript, Tailwind CSS, and legacy Bootstrap components
- Engineered bilingual English/Spanish runtime language switching with `react-i18next`
- Integrated Firebase for PDF storage and supported deployment through Azure Static Web Apps and Google Cloud
- Led Agile/Scrum workflows as Product Owner, including sprint coordination, backlog organization, GitHub collaboration, and project handoff documentation

🔗 **Repository:** [Syllabye-Capstone](https://github.com/ChairForce-1-0/Syllabye-Capstone)

### 🏭 MachinePulse — Industrial IoT Monitoring Dashboard

**Status:** In Progress  
**Stack:** Arduino UNO Q, C++/Python, React, REST APIs, WebSockets, SQL/Firebase, sensors, Azure, Linux, Git/GitHub

MachinePulse is an industrial IoT monitoring prototype designed to simulate real-world machine monitoring, alert thresholds, emergency-stop behavior, and PLC-style fault detection.

**Planned / active features:**
- Collect simulated machine data from temperature, vibration, and input-control sensors
- Visualize live machine status through a React-based dashboard
- Model machine states such as `Running`, `Idle`, `Warning`, `Fault`, and `Emergency Stop`
- Log sensor readings, alerts, and system events for historical review
- Apply prior electrical and automation experience to hardware/software troubleshooting workflows

🔗 **Repository:** Repository Currently Held Locally
